# 管理员登录与账号安全实施计划

依据：工作区《管理员登录与账号安全功能方案.md》（已确认）。

补充要求：用户在实施过程中明确指定管理员初始密码为 `123456`，用于快速演示。采用首次创建默认值，支持环境变量覆盖，不在后续启动覆盖已有密码。

目标：在现有 Spring Boot / HBase / HTML 页面上完成三类登录、永久封禁、解封、邮箱重置及凭证撤销。仅修改认证相关代码与必须接入鉴权的业务入口，不改分析、数据集、岗位查询和大屏。

1. 新增 AccountSecurityService、PasswordResetService、ResetMailService，沿用用户/企业原账号行。HBaseService 新增条件写入和幂等建表；以 security_revision CAS 串行化安全状态变更，验证码消费和密码变更同一 Put。
2. JwtUtil 注入私有密钥，签发类型/角色/版本；JwtAuthFilter 每次请求检查持久化状态。保留 SHA-256 旧密码兼容，新密码使用 BCrypt。
3. 新增管理员与重置接口、初始化器、统一错误反馈。管理员初始化使用密码列不存在条件，保证重启不覆盖。查询结果仅返回安全白名单字段；解封审计与状态同一行原子落盘。
4. 现有企业、简历、聊天、附件入口从身份取主体，校验会话/人才/附件归属；common.js 统一携带 JWT，处理 401。新增后台和找回页面；修改现有登录、注册页面。
5. 用内存 CAS 仓储模拟和 MockMvc 测试三类登录、并发第五次封禁、类型隔离、管理员权限、验证码频率/失效/一次消费、凭证撤销与业务资源归属。运行 `mvn test` 和 `mvn package`。浏览器验证使用模拟 API；真实 HBase/SMTP 在部署环境验收。
6. 输出配置示例、启动与验收说明，审查 diff 范围。未经要求不提交、推送或部署。
