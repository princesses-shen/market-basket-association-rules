## 一、目标与已确认需求

管理员可以发布公告，让网站访客查看。

- **查看范围：** 所有访客，包括未登录访客、普通用户和企业账号。
- **管理操作：** 管理员可以发布、编辑和删除公告。
- **运行版本：** Spring Boot 正式服务与 Python 本地演示服务均支持。
- **数据保存：** 公告持久化保存，服务重启后仍可查看；两个版本各自存储，不自动同步。

## 二、页面与交互

### 管理员端

在管理员导航中新增“公告管理”，保留现有账号安全管理功能。

- 提供标题、正文输入框和已发布公告列表。
- 发布成功后立即对访客可见。
- 支持编辑标题和正文，保留原发布时间。
- 删除前显示确认提示，删除后公告从列表移除，详情不可访问。
- 提交过程中禁用按钮；失败时保留输入并显示错误信息。

### 访客端

- 所有角色的导航新增“网站公告”入口。
- 提供分页公告列表和独立详情页。
- 首页搜索区域下方展示最新 3 条公告及“查看全部”入口。
- 标题和正文按纯文本渲染，保留正文换行，避免执行输入的 HTML 或脚本。
- 列表具有加载、空数据和失败重试状态；详情不存在时提供返回列表入口。
- 首页公告独立加载，失败不影响岗位等原有内容展示。
- 沿用现有公共导航、请求封装和样式，适配窄屏浏览。

## 三、后端与存储

### Spring Boot 正式服务

- 新增公告控制器和业务服务，复用现有 JWT 管理员鉴权及 HBase 访问层。
- 启动时幂等创建 `recruit_announcement` 表，列族为 `info`。
- 补充 HBase 表结构文档。
- 写入权限由后端强制校验，仅公开公告的 GET 接口。

### Python 本地演示服务

- 在现有 HTTP 服务中接入与 Spring Boot 一致的公告接口。
- 复用服务端令牌验证，从账号记录确认管理员角色，不信任前端传入的角色。
- 公告业务与文件存储放入独立模块。
- 数据保存到项目 `data/announcements.json`，运行数据加入 Git 忽略规则。
- 使用临时文件加原子替换保存，保存成功后才返回成功。
- 文件不存在视为空列表；文件损坏或写入失败明确报错，不静默覆盖已有数据。

### 公告数据与规则

| 字段 | 说明 |
| --- | --- |
| ID | 服务端生成的唯一标识 |
| 标题 | 必填，去除首尾空白，最多 100 字 |
| 正文 | 必填，去除首尾空白，最多 10,000 字 |
| 发布人 | 服务端记录，公开页面统一显示“管理员” |
| 发布时间 | 服务端生成，编辑时保持不变 |
| 更新时间 | 服务端生成，编辑时更新 |

- 两个后端采用一致的校验规则。
- 列表按发布时间倒序排列，以 ID 作为同一时间下的稳定排序依据。
- 编辑不改变原发布时间及其排序位置。

## 四、接口约定

两个后端提供一致的接口，前端共用同一套页面。

| 方法 | 路径 | 用途 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/announcements?page=1&size=10` | 分页列表 | 所有访客 |
| GET | `/api/announcements/{id}` | 公告详情 | 所有访客 |
| POST | `/api/admin/announcements` | 发布公告 | 管理员 |
| POST | `/api/admin/announcements/{id}/update` | 修改标题和正文 | 管理员 |
| POST | `/api/admin/announcements/{id}/delete` | 删除公告 | 管理员 |

- 发布和编辑请求提交标题、正文，发布人和时间由服务端确定。
- 列表返回 `code、items、total、page、size`，列表项省略正文。
- 详情、发布和编辑结果通过 `item` 返回公告。
- 页码从 1 开始，默认每页 10 条，分页大小限制为 1–50。
- 沿用现有 `code、msg` 错误格式。

| HTTP 状态码 | 场景 |
| --- | --- |
| 400 | 参数错误或内容校验失败 |
| 401 | 管理操作未登录或凭证无效 |
| 403 | 非管理员执行管理操作 |
| 404 | 公告不存在或已删除 |
| 503 | 存储不可用或保存失败 |

## 六、测试与验收

### 权限

- 游客、普通用户和企业账号均可浏览列表和详情。
- 仅管理员可以发布、编辑和删除。
- 未登录请求被拒绝；普通用户和企业账号无法通过直接调用接口或修改前端角色获得管理权限。

### 完整业务流程

- 管理员发布后，首页和公告列表可以查看新公告。
- 首页只展示最新 3 条，分页和排序正确。
- 编辑后详情内容更新，原发布时间不变。
- 删除后列表不再显示该公告，详情请求返回 404。

### 输入与异常

- 覆盖空白内容、超长内容、无效分页参数和不存在的 ID。
- HTML、脚本等输入按普通文字展示，不执行。
- 保存失败不显示成功，不清空管理员输入。
- 首页公告加载失败不影响岗位展示。

### 持久化与回归

- Python 使用临时目录验证重新加载、写入失败和损坏文件处理。
- Spring Boot 复用现有 MockMvc 和模拟 HBase 测试模式；在可用 HBase 环境验证服务重启后数据保留。
- 使用 Playwright 验证管理员操作、游客浏览和窄屏布局。
- 运行现有账号安全测试，确认登录、权限校验和账号管理功能正常。

## 七、默认边界

- 本次不包含草稿、定时发布、置顶、下架、附件、富文本、评论或消息推送。
- 删除采用直接删除；不增加回收站或恢复功能。
- 两个运行版本的数据不自动同步。
- 实施范围为代码、验证和使用说明，不包含远程部署。
